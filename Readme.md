# NovaPurge

> **A smarter way to keep Windows clean, organized, and under control.**

NovaPurge is a Windows system utility that brings essential PC
maintenance and system-management tools together in one application.

Instead of relying on multiple separate utilities, NovaPurge provides a
single interface for cleaning unnecessary data, understanding storage
usage, managing startup applications, and performing other
system-maintenance tasks.

## Features

-   • **System Cleanup** --- identify and remove unnecessary files
-   • **Storage Scanner** --- analyze disk usage and locate
    space-consuming data
-   • **Duplicate File Detection** --- find duplicate files that may be
    taking up unnecessary storage
-   • **Large File Analysis** --- identify unusually large files and
    folders
-   • **Memory Booster** --- manage memory-related cleanup tasks
-   • **Privacy Cleaner** --- clean selected privacy-related traces
-   • **Startup Manager** --- manage applications that launch with
    Windows
-   • **App Uninstaller** --- remove unwanted applications
-   • **Disk Treemap** --- visualize how storage is being used
-   • **DISM Cleaner** --- access Windows component/image cleanup
    operations
-   • **System Information** --- view useful information about the
    Windows system

## Platform

NovaPurge is currently designed for:

-   **Windows 10 / Windows 11**
-   **64-bit systems**

The application is distributed as a standalone Windows executable, so
Python does not need to be installed separately.

## 🚀 Getting Started

1.  Download `NovaPurge.exe` from the latest GitHub Release.
2.  Place it somewhere convenient on your Windows PC.
3.  Launch the application.
4.  Some system-level operations may require **Administrator
    privileges**.
5.  Review what an operation will remove or change before confirming it.

## ⚠️ Important Notes

NovaPurge performs system-maintenance operations. Some features can
modify files, startup configuration, installed applications, or Windows
components.

**Always review the selected operation before confirming it.**

For advanced cleanup operations, running NovaPurge as Administrator may
be required.

Windows Defender or SmartScreen may display a warning because the
distributed executable is not digitally signed. If this occurs, verify
that you downloaded the file from this repository's official
**Releases** page before running it.

## 🧩 Project Structure

NovaPurge is organized into separate utility modules for different
maintenance tasks, including cleanup, duplicate detection, memory
management, privacy cleaning, startup management, application removal,
storage visualization, and DISM operations.

## 🎯 Project Goals

NovaPurge was created with three main goals:

1.  **Centralize** common Windows maintenance tasks.
2.  **Simplify** system cleanup for everyday users.
3.  **Provide** useful system-management tools through one focused
    application.
